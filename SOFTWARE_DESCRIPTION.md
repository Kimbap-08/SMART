# Software Description

### 1. Brief Description of the System

S.M.A.R.T. (Student Management and Academic Records Tracking) is a Windows desktop application that helps administrators and instructors manage academic records and course activities in one system.

### 2. Scope and Limitations

The system supports role-based accounts, student and instructor records, courses and instructor assignments, enrollments, schedules, attendance, assessments, announcements, calendar items, notes, settings, and help messages, but it does not provide student self-service, online registration, payment processing, external learning-management integration, automatic email or SMS notifications, remote synchronization, or independent verification of user-entered data.

### 3. Benefits and Values

By centralizing academic records in structured local databases and providing role-specific tools, S.M.A.R.T. helps users manage information more efficiently, consistently, and clearly.

## 4. Platform Requirements (Minimum System Requirement)

| **Component**       | **Minimum Requirement**                                                                                                    |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Operating System    | Windows 10 or Windows 11, 64-bit                                                                                           |
| Processor           | Intel Core i3 or equivalent, 1 GHz or faster, 64-bit                                                                       |
| Memory              | 4 GB RAM (8 GB recommended)                                                                                                |
| Storage             | 4 GB available space for the application, .NET runtime, LocalDB, and database files                                        |
| Display             | 1366 × 768 resolution (the main screens are designed at 1540 × 845 and run maximized, so a larger display is recommended) |
| Keyboard and Mouse  | Standard keyboard and mouse                                                                                                |
| Required Software   | .NET 9 Windows Desktop Runtime and SQL Server Express LocalDB                                                               |
| Development Tools   | Visual Studio 2022 with .NET desktop development workload and .NET 9 SDK, if building from source                          |
| Network             | Internet is not required for normal local use; needed to restore NuGet packages or download/setup tools                     |
